# EKT Assistant frontend

Исходники клиентского прототипа для подключения к FastAPI. В архиве нет `node_modules`, `.env`, API-паролей, токенов или ключей LLM.

## Структура

```text
src/
  app.js       # интерфейс, сценарии, модальные окна, WebMCP
  core.js      # каталог демо, поиск, аналоги, правила корзины
  style.css    # адаптивный интерфейс
public/
  assets/      # изображения
  supplier-catalog.json  # датированный снимок ekt.kz API
tests/
scripts/
index.html
```

## Локальный запуск

Нужен Node.js 20.19 или новее. У проекта нет npm-зависимостей.

```bash
npm start
```

Откройте `http://127.0.0.1:4173`.

```bash
npm run check
```

## Подключение к FastAPI

FastAPI может раздавать `index.html`, папку `src/` и `public/` как статические файлы. Текущий фронтенд обращается только к `./supplier-catalog.json`; замените это на `/api/catalog/...` после появления backend.

Не передавайте Basic Auth, ключи LLM или доступ к корзине в браузер. Backend должен:

1. Хранить доступ к ekt.kz и LLM в переменных окружения.
2. Перед добавлением повторно проверять цену, остаток, кратность и доступный склад.
3. Создавать предложение корзины с `proposalId`, TTL и idempotency key.
4. Применять товар только после отдельного подтверждения пользователя.
5. Проверять формат, размер и содержимое вложений на сервере.

`src/core.js` содержит только синтетические данные `DEMO-*`. `public/supplier-catalog.json` — отдельная датированная выборка API; не используйте её как актуальную цену или остаток. Отзывы и история цены в демо синтетические.

## Секреты

`.env.example` показывает только имена серверных переменных. Скопируйте его в `.env` на backend-машине. Не коммитьте `.env` и не включайте его в архивы.
