# Файлы для проверки загрузки

Все товары и количества в образцах учебные. Используйте их с каталогом `CATALOG_MODE=demo`.

| Файл | Содержимое |
|---|---|
| `sample.xlsx` | Excel: DEMO-003 — 3 м, DEMO-004 — 2 шт. |
| `sample.docx` | Word: тот же список из двух товаров. |
| `sample.pdf` | PDF с доступным текстом: тот же список из двух товаров. |
| `sample.jpg` | Учебная этикетка DEMO-004, C16, количество 2 шт. |

Загрузите один файл через скрепку в чате. Сверьте распознанный текст и найденные товары. У DEMO-003 нет остатка; для него предусмотрен доступный кандидат DEMO-007 с объяснением совпадений. Сама загрузка файла не добавляет товары в корзину: количество и добавление подтверждаются отдельно.

Для фото нужен настроенный OpenAI OCR. Таблица, Word и текстовый PDF читаются локально. Файлы не содержат настоящих заказов, ключей, платёжных данных или утверждений о реальном ассортименте ekt.kz.
