# Подключённый frontend EKT v0.5

Этот интерфейс работает с FastAPI из общего проекта. Страница и /api раздаются одним сервером.
Исходный дизайн человека 3 сохранён, поиск, чат и корзина подключены к backend.

## Запуск

Из корневой папки ekt-assistant-backend после установки Python-зависимостей:

```powershell
python run.py
```

Откройте http://127.0.0.1:8001/. Для отдельной демо-корзины:

```powershell
python run.py --demo
```

Откройте http://127.0.0.1:8002/. При работе через .venv используйте
.\.venv\Scripts\python.exe вместо python. Остановка процесса — Ctrl+C.
npm install, сборка и отдельный Node-сервер не нужны.

## Файлы

- index.html — входная страница.
- src/app.js — интерфейс и запросы каталога, чата, сессии и корзины.
- src/core.js — API-клиент, проверка явного подтверждения и форматирование неизвестных значений.
- src/style.css — стили исходного фронтенда.
- src/integration.css — стили для карточек backend и мобильного вида.
- public/assets — изображения и иллюстрации категорий.
- tests — проверки API-клиента и вспомогательной логики.

Секреты и адрес внешнего AI во frontend не передаются. Вызовы используют относительные пути /api.
sessionStorage хранит ID сессии; данные корзины принадлежат backend.
Нажатие «Проверить и продолжить» создаёт предложение, «Да, добавить» отправляет отдельный confirm.
Изменение количества требует нового предложения. Повтор подтверждения одного предложения не дублирует товар.

В основном режиме используются 40 записей снимка EKT с неизвестными валютой, единицей и датой актуальности.
Такие записи недоступны для добавления. Режим --demo даёт 6 отдельных вымышленных товаров для показа корзины.
Предварительные аналоги не означают подтверждённую взаимозаменяемость.

Текущая сборка на русском. Синтетические отзывы, история цен, локальная корзина и выбор файлов
без обработки удалены из подключённого интерфейса. Подключение соответствующих функций требует backend API.

## Тесты

Нужен Node.js 20.19 или новее только для запуска JS-тестов. Из корня проекта:

```powershell
node --test frontend/tests/core.test.mjs
```

Результат текущего прогона: 8 passed. Полный API-контракт и запуск backend описаны в корневом README.md.
