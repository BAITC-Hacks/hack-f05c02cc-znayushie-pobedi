# Статус прототипа

## Готово

- Виджет и полная страница каталога с адаптивной мобильной компоновкой.
- Поиск, карточка, характеристики, склады, сертификаты, аналоги и сравнение.
- Безопасный сценарий корзины: предложение, явное подтверждение, отмена, срок действия и защита от повторного добавления.
- Приём PDF, DOCX, XLSX/XLS, JPG и PNG с ограничением размера, проверкой типа и изоляцией текста вложения от команд корзины.
- RU/KK/EN: выбор языка в интерфейсе передаётся backend; каталоговые fallback-ответы и ответы подключённой модели формируются на выбранном языке.
- Озвучивание последнего ответа запускается только пользователем; автоматическая озвучка выключена.
- Защита клиентских данных: секреты не включены, файлы не сохраняются в сессии, API не принимает платёжные данные.

## Что нельзя достоверно «доделать» без партнёра EKT

В полученном снимке каталога отсутствуют либо не подтверждены актуальные остатки, валюта, единицы продажи и дата обновления для большинства товаров. Поэтому обычные записи EKT показываются честно как снимок и не добавляются в корзину. Отзывы, рейтинг качества, история изменения цен и обещанная дата поставки также не переданы. Их нельзя подставлять демонстрационными данными в рабочий режим.

Для production нужны: защищённый API актуального каталога и остатков, API корзины/оформления, подтверждённые цены и единицы, источник отзывов/даты/состава, поставки, авторизация и постоянное хранилище сессий. После этого демо-обработчик `SessionStore` заменяется адаптером корзины ekt.kz без изменения правила явного подтверждения.
