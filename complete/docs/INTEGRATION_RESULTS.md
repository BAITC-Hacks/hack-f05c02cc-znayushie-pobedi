# Результат интеграции — EKT Assistant v0.5

## Состав общей сборки

Получены полный ekt_backend_handoff.zip человека 1 и EKT-Assistant-Frontend-Source.zip человека 3.
Каталог, FastAPI и интерфейс объединены в архив ekt-assistant-full.zip.

Пакет ekt_catalog/ сохранён без изменения: CatalogService, нормализатор, схема, JSON и исходный router.
Адаптер app/catalog.py использует единый CatalogService для поиска, карточек, снимков остатков и аналогов.
Исходный router /catalog не монтируется. Единый источник нормализованных записей:
ekt_catalog/data/products.normalized.json. Его SHA-256:

```text
293df509ead52069e76786ccbdb6d8977ce14f6b0d2584cae0d844a8547d0561
```

Фронтенд сохраняет стиль, карточки, сравнение и мобильную компоновку переданного проекта.
Сценарные ответы и локальная корзина заменены запросами к backend. В sessionStorage хранится ID сессии.
Неподключённые отзывы, история цен и выбор файлов без обработки исключены из интерфейса.
Отдельная выборка supplier-catalog.json не используется.

## Изменения API и запуска

- Существующие маршруты /api и поля адаптера сохранены.
- POST /api/sessions создаёт пустую сессию без вызова AI.
- GET /api/products возвращает products, total, source, catalog, offset, limit; limit — от 1 до 100.
- Страница раздаётся по /, JS/CSS — по /src, иллюстрации — по /assets.
- Статические маршруты не открывают корень проекта, файлы окружения, Python-код и документы.
- При отсутствии frontend/index.html API продолжает работать.
- python run.py: normalized на 127.0.0.1:8001, настроенный провайдер AI.
- python run.py --demo: 6 демо-товаров на 127.0.0.1:8002, AI_PROVIDER=demo; .env.local не меняется.
- Дополнительный параметр --port позволяет выбрать порт. Остановка — Ctrl+C.

Для сайта не нужны npm-зависимости, сборка и отдельный Node-сервер.
Node.js используется только для тестов фронтенда. Ключ AI остаётся в настройках backend.

## Данные, которые ещё нужны

Каталог EKT содержит снимок 40 товаров. У 39 неизвестно количество; у всех неизвестны
валюта, единица продажи и дата актуальности. У 515291 конфликт тока 160/250 А.
Модуль не содержит embeddings и обновления через живое API.

Добавление записей снимка возвращает 409 live_stock_check_required.
Для реальных товаров нужны актуальные продаваемые остатки, цены, подтверждённые валюта и единица,
а также интеграция корзины магазина. Демо-корзина использует 6 отдельных вымышленных товаров.
Сессии находятся в памяти одного процесса. Перезапуск их очищает; постоянное хранилище
и пользовательская авторизация пока не подключены.

Ключи, .env.local и пароли не включаются в общий архив.
