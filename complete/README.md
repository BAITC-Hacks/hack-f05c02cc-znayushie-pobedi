# EKT Assistant

Прототип ИИ-ассистента для каталога электротехники. Frontend и FastAPI backend запускаются одним локальным сервером. Ассистент ищет товары, показывает характеристики, сертификаты и предварительные аналоги, принимает PDF/Excel/Word/изображения и создаёт предложение для корзины. Товар добавляется только отдельной кнопкой «Да, добавить».

## Возможности

- Каталог, поиск и карточки: цена, единица продажи, снимок наличия, характеристики, склады и сертификаты.
- Аналоги с причиной выбора и предупреждением, что взаимозаменяемость требует технической проверки.
- Сравнение до трёх товаров без закрытия страницы.
- Чат, история в пределах серверной сессии, загрузка PDF, DOCX, XLSX/XLS, JPG и PNG до 10 МБ.
- Выбор языка ответа: русский, казахский или английский. Внешняя модель отвечает на выбранном языке; безопасный каталожный ответ также локализован.
- Кнопка озвучивания последнего ответа. Озвучивание никогда не включается само.
- Два режима: `normalized` для снимка EKT и `--demo` для безопасного сценария добавления в демо-корзину.
- Desktop, мобильная компоновка и режим компактного виджета: `/?widget=1`.

## Быстрый запуск

Нужен Python 3.11+.

```powershell
cd EKT-Assistant-Complete
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python run.py --demo
```

Откройте `http://127.0.0.1:8002/`. Для просмотра снимка EKT используйте `python run.py`, затем откройте `http://127.0.0.1:8001/`.

`--demo` не использует платёжные данные и не создаёт заказ на ekt.kz. Это единственный режим, в котором разрешено демонстрационное добавление товара в локальную демо-корзину.

## Конфигурация

Скопируйте `.env.example` в `.env.local` и задайте провайдера, если нужен ответ внешней модели. Не коммитьте `.env.local`. В браузер нельзя передавать ключи API, пароль EKT или платёжные данные.

При `AI_PROVIDER=demo` поиск, карточки, прикрепление текстовых документов и сценарий корзины работают без ключа. Распознавание фото и сканов требует настройки OpenAI в backend.

## Контракт корзины

1. Интерфейс вызывает `POST /api/sessions/{id}/cart/proposals`.
2. Backend проверяет количество и создаёт неизменяемое предложение на 10 минут.
3. Только отдельное нажатие вызывает `POST .../confirm` с `{ "confirm": true }`.
4. Текст «да» в чате, файл и открытие карточки не меняют корзину.

## Структура

- `app/` — FastAPI, чат, сессии, корзина и обработка вложений.
- `ekt_catalog/` — нормализация и поиск по каталогу.
- `frontend/` — виджет, карточки, адаптивный интерфейс и JS-тесты.
- `data/` — демонстрационные условия и данные.
- `docs/COMPLETION_STATUS.md` — готовые функции и интеграционные данные, которые должен предоставить партнёр.

Подробнее об API и ограничениях данных — в `docs/INTEGRATION_RESULTS.md`.
